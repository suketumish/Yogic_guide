│                         HYBRID FUSION LOGIC                                   │
└──────────────────────────────────────────────────────────────────────────────┘
│                                                                               │
│  Rule 1: HIGH CONFIDENCE AGREEMENT                                           │
│  ├─ IF image_conf > 0.85 AND keypoint_conf > 0.80 AND predictions match     │
│  └─ THEN final = prediction, conf = average, status = HIGH_CONFIDENCE        │
│                                                                               │
│  Rule 2: DISAGREEMENT - FAVOR HIGHER CONFIDENCE                              │
│  ├─ IF predictions differ AND |conf_diff| > 0.2                              │
│  └─ THEN final = higher_conf_prediction, conf = max * 0.9                    │
│                                                                               │
│  Rule 3: BOTH LOW CONFIDENCE                                                 │
│  ├─ IF image_conf < 0.6 AND keypoint_conf < 0.6                             │
│  └─ THEN final = UNCERTAIN, conf = 0.0, status = NEEDS_BETTER_IMAGE         │
│                                                                               │
│  Rule 4: KEYPOINT PRIORITY (for geometric poses)                             │
│  ├─ IF pose in [warrior2, triangle, tree, plank] AND keypoint_conf > 0.75   │
│  └─ THEN final = keypoint_prediction, status = KEYPOINT_PRIORITY            │
│                                                                               │
│  Rule 5: DEFAULT                                                              │
│  └─ Use image model prediction                                               │
